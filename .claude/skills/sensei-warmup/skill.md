# React/TypeScript Warm-Up

Read ROADMAP.md and find the first unchecked `[ ]` item in the current phase.

## Steps
1. Read ROADMAP.md
2. Find the current phase (look for "YOU ARE HERE" or the first phase with unchecked items)
3. Pick the **first unchecked item** in that phase
4. Present it as a friendly challenge — one sentence of context, then "ready?"
5. If all items in the phase are done — congratulate and point to the next phase
6. If LEARNER_PROFILE.md exists — read it and tailor the framing to their background and style

## Tone
- Energetic, like a coach starting practice
- One item at a time — don't overwhelm
- If it's a TypeScript concept, frame it as "let's see how you'd type this"
- If it's a React pattern, frame it as "here's a real problem — how would you solve it?"
